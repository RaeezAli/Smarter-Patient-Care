About PatientTrace

⚠️ Safety Statement & Clinical Use Disclaimer

This application is a research and educational prototype only developed for hackathon demonstration purposes. It is NOT intended for clinical use, diagnosis, medical decision-making, triage, treatment planning, or emergency decisions. All dataset timestamps have been randomly date-shifted per patient as part of the PhysioNet de-identification protocol.

What This Tool Does

PatientTrace is a deterministic clinical data exploration tool built on the MIMIC-IV Clinical Database Demo dataset. It extracts and constructs structured patient timelines and answers targeted clinical history questions directly from relational SQLite database tables. Every presented fact is bound to an explicit database citation tag indicating the source table and primary/composite row identifier.

What This Tool Does NOT Do

  • No LLM Generative Answering: Does not use Large Language Models (LLMs) or generative AI APIs for question answering, eliminating hallucination risks.
  • No Clinical Diagnostics: Does not infer diagnoses, treatment recommendations, or risk scores.
  • No Uncited Outputs: Does not display any event or record without attached primary data source citations.
  • No Calendar Chronology: Does not reflect real calendar dates (all dates are shifted per patient).

Data Source & License

Data is sourced from the MIMIC-IV Clinical Database Demo v2.2 (PhysioNet).

Reference: PhysioNet MIMIC-IV Demo v2.2. Data contains hospital-wide (`hosp`) and intensive care unit (`icu`) modules across 100 de-identified patient stays.
